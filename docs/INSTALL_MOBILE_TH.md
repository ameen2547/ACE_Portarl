# วิธีติดตั้ง ACE Content Portal บนมือถือ

ACE Content Portal ทำงานเป็น Google Apps Script Web App จึงติดตั้งใช้งานบนมือถือโดยเพิ่มทางลัดไว้บนหน้าจอหลัก ไม่ใช่แอป APK ที่ดาวน์โหลดจาก Play Store หรือ App Store ผู้ใช้ต้องเชื่อมต่ออินเทอร์เน็ตและลงชื่อเข้าใช้ด้วยบัญชี Google ที่ระบบอนุญาต

## Android

1. ส่งลิงก์ Web App ให้โทรศัพท์ หรือเปิดลิงก์จากปุ่ม **ติดตั้งบนมือถือ / วิธีใช้** ในระบบ
2. เปิดลิงก์ด้วย Google Chrome
3. แตะเมนูจุดสามจุด `⋮` มุมขวาบน
4. เลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** (ข้อความอาจต่างกันตามรุ่น Android และ Chrome)
5. ยืนยันการติดตั้ง แล้วเปิด ACE Content Portal จากไอคอนที่เพิ่มไว้

## iPhone และ iPad

1. ส่งลิงก์ Web App ให้โทรศัพท์ หรือเปิดลิงก์จากปุ่ม **ติดตั้งบนมือถือ / วิธีใช้** ในระบบ
2. เปิดลิงก์ด้วย Safari
3. แตะปุ่มแชร์ (สี่เหลี่ยมพร้อมลูกศรชี้ขึ้น)
4. เลือก **เพิ่มไปยังหน้าจอโฮม** หากไม่เห็น ให้เลื่อนรายการลงหรือแตะ **แก้ไขการทำงาน**
5. ตรวจชื่อทางลัด แล้วแตะ **เพิ่ม**

## การใช้งานและแก้ปัญหาเบื้องต้น

- เปิดทางลัดและลงชื่อเข้าใช้ Google Workspace ตามสิทธิ์ของระบบ
- หากขึ้นว่าไม่มีสิทธิ์ ให้ตรวจว่าบัญชี Google ที่เปิดอยู่ได้รับอนุญาตให้ใช้ Web App แล้ว
- หากอัปเดตระบบแล้วหน้าเดิมค้าง ให้ปิดหน้าแอปแล้วเปิดใหม่ หรือเอาทางลัดออกและเพิ่มใหม่
- ทางลัดต้องใช้อินเทอร์เน็ต และใช้ URL เดียวกับ Web App ที่ผู้ดูแลเผยแพร่
- `/dev` ใช้สำหรับทดสอบและอาจเปลี่ยนตามซอร์สล่าสุด ส่วนผู้ใช้ทั่วไปควรใช้ URL `/exec` ที่เผยแพร่แล้ว

## การดาวน์โหลดรายงานลงมือถือ

เมื่อส่งออก CSV หรือ Excel ให้แตะ **บันทึกหรือแชร์ไฟล์** แล้วเลือกบันทึกลง Files/Downloads หรือแอปจัดเก็บไฟล์ของอุปกรณ์ ส่วน PDF ใช้เมนูพิมพ์ของเบราว์เซอร์ แล้วเลือกบันทึกเป็น PDF หากมีตัวเลือกนี้
